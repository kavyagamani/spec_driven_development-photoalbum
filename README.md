# 🌱 Spec-Driven Development - Photo Album App

## 📌 Project Overview
This project is developed using the **Spec-Driven Development (SDD)** approach.  
It demonstrates how software can be built by defining specifications first and then implementing the system step-by-step.

In this project, a **Photo Album Application** is created where users can organize and manage photos.

---

## 🎯 Objective
- To apply Spec-Driven Development methodology  
- To build a photo album management system  
- To organize photos based on categories/date  

---

## 💡 What is Spec-Driven Development?

Spec-Driven Development is a process where:
- Specifications define the system first  
- Then planning and tasks are generated  
- Finally implementation is done  

👉 Instead of coding first, we follow a structured approach based on requirements :contentReference[oaicite:0]{index=0}  

---

## 🔄 Development Process

1. **Constitution** – Define project rules  
2. **Specification** – Describe features  
3. **Planning** – Decide technology & design  
4. **Tasks** – Break work into steps  
5. **Implementation** – Develop application  

---

## 🚀 Features
- Create photo albums  
- Organize photos by date  
- Drag and drop albums  
- View photos in grid format  

---

## 🛠️ Technologies Used
- HTML, CSS, JavaScript  
- (Optional) Angular / React  
- Local storage / Database
